# Whitecat-Launcher — MyLauncher

Офлайн-лаунчер Minecraft на **Tauri 2 + React 18 + TypeScript + Rust** (бэкенд `lighty-launcher`).

## Часть 2/4 — что добавлено

**Версии и скачивание**
- Список версий из официального API Mojang (`piston-meta.mojang.com/mc/game/version_manifest_v2.json`):
  релизы, снапшоты и старые версии в выпадающем списке с группировкой.
- Кеш манифеста на диске (`version_manifest.json` в папке конфигурации): интерфейс
  открывается мгновенно, кеш считается свежим 30 минут.
- Фоновое обновление: при старте и далее раз в 10 минут лаунчер проверяет кеш и молча
  обновляет его раз в час, присылая событие `versions_updated` в интерфейс.
- Кнопка «Скачать игру» в карточке профиля и кнопка ручного обновления списка версий.
- Асинхронное скачивание в **8 потоков**: клиент, библиотеки (включая нативки), индекс
  ассетов и все объекты ассетов. Проверка SHA-1, `.part`-файлы, пропуск уже скачанного.
- Красивый прогресс-бар: полоса загрузки, проценты, имя текущего файла, счётчик файлов,
  объём (скачано / всего) и скорость.

**Вкладка «Контент» (Modrinth API)**
- Поиск с debounce по проектам Modrinth.
- Фильтры: тип контента (моды, ресурспаки, шейдеры, сборки), версия игры, загрузчик
  (Fabric / Forge / NeoForge / Quilt) и сортировка (релевантность, скачивания, новинки).
- Карточки контента: иконка, название, автор, количество скачиваний, описание, теги
  и кнопка «Установить» с состоянием загрузки прямо на карточке.
- Бесконечная подгрузка («Показать ещё») и список установленных сборок-инстансов.

**Логика установки**
- Моды → `mods/`, ресурспаки → `resourcepacks/`, шейдеры → `shaderpacks/`.
- Сборки `.mrpack`: скачивание архива, чтение `modrinth.index.json`, распаковка
  `overrides/` и `client-overrides/`, загрузка файлов сборки и создание отдельного
  инстанса в `instances/<slug>/` с `instance.json` (версия игры, загрузчик, число модов).
- Очередь загрузок в Rust: задачи выполняются последовательно, каждая с прогрессом,
  отменой и удалением из списка; события `download_queue` обновляют интерфейс.
- Все установки идут в папку игры из настроек (или в папку данных приложения).

## Часть 1/4 — что уже работало

**Интерфейс** (тёмная тема, glassmorphism, неоново-синий акцент):
- Splash-экран: логотип + «MyLauncher», появление/растворение на Framer Motion, 2 секунды.
- Левое меню: вкладки «Главная», «Контент», «Настройки» (иконки Lucide, подсветка активной).
- Карточка профиля: ник, список версий, загрузчики Vanilla/Fabric/Forge, слайдер RAM 1–16 ГБ.
- Кнопка «ИГРАТЬ» с эффектом свечения и статус-бар («Готов к запуску» и т.д.).
- Плавные анимации переключения вкладок (AnimatePresence), hover-эффекты.

**Бэкенд (Rust):**
- Офлайн-запуск без аккаунта Mojang: legacy-токен, `auth_session`, offline-UUID (MD5 «OfflinePlayer:<ник>»).
- Полный пайплайн: манифест Mojang → JSON версии → клиент → библиотеки (включая нативки, старые и новые форматы) → ассеты (форматы `objects` и `map`) → сборка командной строки по правилам манифеста.
- Vanilla — полностью, Fabric — через официальный loader-профиль (meta.fabricmc.net).
- Автоопределение Java: встроенный JDK → `JAVA_HOME` → `PATH` → типовые каталоги (Adoptium, Microsoft, BellSoft, Corretto, Zulu, `/usr/lib/jvm`, JVM на macOS).
- Скачивание JDK 21 (Adoptium API) с прогрессом (событие `jdk_progress`), автоустановка в папку лаунчера (zip / tar.gz).
- Настройки сохраняются в `settings.json` (app config dir); лог игры — `launcher.log` в папке игры.

## Запуск

```bash
npm install
npm run tauri dev
```

## Сборка дистрибутива

```bash
npm run tauri build
```

## Структура

```
src/                      # React + TS (фронтенд)
  components/             # Splash, Sidebar, вкладки, DownloadBar (прогресс и очередь)
  lib/api.ts              # обёртки invoke-команд (+ браузерный режим для предпросмотра)
  types.ts                # типы версий, контента и очереди загрузок
src-tauri/
  src/lib.rs              # Tauri-команды, общие типы, HTTP-клиент
  src/versions.rs         # список версий piston-meta: кеш, фоновое обновление
  src/installer.rs        # план установки версии и многопоточный загрузчик
  src/modrinth.rs         # поиск Modrinth, установка модов/ресурспаков/сборок
  src/queue.rs            # очередь загрузок с прогрессом и отменой
  src/java.rs             # автоопределение Java
  src/jdk.rs              # скачивание/установка JDK
  src/minecraft.rs        # офлайн-запуск, пайплайн установки
  src/settings.rs         # настройки и папка игры
scripts/make-icons.mjs    # генерация иконок (npm run icons)
```

## События бэкенда

| Событие | Payload | Когда |
| --- | --- | --- |
| `jdk_progress` | `{stage, message, percent}` | скачивание JDK |
| `launch_progress` | `{stage, message, percent}` | запуск игры |
| `versions_updated` | `VersionList` | фоновое обновление манифеста |
| `download_queue` | `DownloadTask[]` | любое изменение очереди/прогресса |
